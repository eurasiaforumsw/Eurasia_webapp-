🫧 Bubble Button Effect

ปุ่มแบบ Animated พร้อม Bubble Effect เมื่อ Hover

Primary Buttons (Cyan)

สำหรับ Action หลัก
<button class="button-bubble">บันทึกข้อมูล</button>

Success Buttons (Green)

สำหรับ Confirm, Approve
<button class="button-bubble button-bubble--success">✓ ยืนยัน</button>

Warning Buttons (Amber)

สำหรับ Draft, Pending
<button class="button-bubble button-bubble--warning">⚠ บันทึกแบบร่าง</button>

Danger Buttons (Red)

สำหรับ Delete, Cancel
<button class="button-bubble button-bubble--danger">✕ ลบ</button>

วิธีใช้ใน React/Next.js

import BubbleButton from '@/components/ui/BubbleButton'; // Primary <BubbleButton variant="primary" onClick={handleSave}> บันทึกข้อมูล </BubbleButton> // Success <BubbleButton variant="success" type="submit"> ✓ ยืนยัน </BubbleButton> // Warning <BubbleButton variant="warning"> ⚠ บันทึกแบบร่าง </BubbleButton> // Danger <BubbleButton variant="danger" onClick={handleDelete}> ✕ ลบ </BubbleButton>
