Usage Guide

When to use each loader:

  • 3D Loader: Full-page loading, major actions, data fetching
  • Dots Loader: Inline text loading (e.g., "Loading comments...")
  • Progress Bar: Page transitions, file uploads, multi-step progress
  • Skeleton: Content placeholders (cards, lists, profiles)
  • Inline Spinner: Button loading states, small actions
