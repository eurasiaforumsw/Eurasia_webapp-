🎯 RegistrationButton Component

Complete visual reference for all 8 button states

1️⃣ Loading

Initial state while fetching registration data and checking authentication status.

Non-clickable

2️⃣ Login to Register

User is not authenticated. Clicking redirects to login page with return URL.

Clickable - Redirects

3️⃣ Registration Closed

Registration is disabled in admin settings (registration_enabled = false).

Non-clickable

4️⃣ Registration Opens Soon

Current time is before registration_starts_at date. Tooltip shows opening date.

Non-clickable

5️⃣ Registration Ended

Current time is after registration_ends_at date. Registration period has passed.

Non-clickable

6️⃣ Event Full

Maximum attendees reached (currentRegistrations >= maxAttendees).

Non-clickable

7️⃣ You are Registered

User has already registered for this event. Success variant with checkmark.

Non-clickable

8️⃣ Register Now

User is authenticated, registration is open, and event is not full. Opens modal.

Clickable - Opens Modal
